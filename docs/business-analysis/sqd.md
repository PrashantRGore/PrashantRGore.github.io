# System Sequence Diagrams (SQD)

The interactive sequence diagrams below illustrate **actor-to-system message flows** for all key CVH workflows: patient registration, appointment scheduling, clinical consultation, billing, discharge, and more. Each diagram shows the precise sequence of system calls and responses between user roles and HMS modules.
