Architecture Assumptions (Prototype Scope)
1. All requests processed synchronously — no async queues.
2. Single application server; single SQLite database instance (local).
3. Audit logging executes synchronously within the same transaction. If audit write fails, the business transaction is still committed and a system-level error is logged to console.
4. No external messaging (SMS/email) in prototype — triggers are logged only.
5. RBAC enforced at application router level (app.py) on every page load — not at DB level in prototype.
